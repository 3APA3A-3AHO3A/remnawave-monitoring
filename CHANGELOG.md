# Changelog

Версии — по тегам `vX.Y.Z`. Релиз на GitHub собирается из раздела этого файла автоматически.

## 1.1.0 — 2026-10-23
**Алерты**
- «Хост не принимает клиентов» вместо «Нода не принимает клиентов»: проверяется именно хост (точка входа), у одной ноды их может быть несколько.
- В алерте видно, куда ведёт хост: «LTE 3 · OVRO → CDN 1 · FixErrorVPN». Нода находится сама, если адрес хоста совпадает с IP ноды в любой из панелей. Для хостов через Cloudflare или промежуточный сервер — настройка `host_exit` у панели: `host_exit = { "LTE 3" = "CDN 1" }`.
- Упали все хосты одной ноды — проблема на ноде; упал один — на пути этого хоста до неё.

## 1.0.0 — 2026-10-23
Первый релиз с номером версии. Всё, что было сделано до него:

**Мониторинг**
- Несколько панелей в одной установке: `config.toml`, у каждой панели свой чат и топик Telegram, одинаковые хосты разных панелей проверяются один раз.
- Проверки хостов через xray-checker (Подключение, WARP, Psiphon) со своим образом: поддержка Hysteria2 с Salamander `packetSize` и повторные попытки. Тег `MONITORING_LITE` — одна лёгкая проверка для LTE и хостов с лимитом трафика.
- Проба из РФ (blackbox exporter): видна блокировка IP хоста и недоступность сайтов изнутри России. Хосты на UDP в пробы не попадают.
- Проверка сайтов: код ответа, время, ключевое слово, срок сертификата; `any_status` для страниц с закрытым корнем.
- Здоровье панелей: задержка, память и время работы процессов; алерты «тормозит», «перезапустился», «ест много памяти».

**Алерты и сводка**
- Сообщения о восстановлении отдельно от продолжающихся сбоев, напоминания раз в час.
- «Аутбаунд не отвечает» на паузе: за выходами стоят балансировщики с резервом, реальный отказ ловят проверки WARP / Psiphon.
- Ежедневная сводка без дублей и минутных сбоев; в GeoCheck подсвечивается только новое со вчера.

**Дашборд**
- Таблица нод «всё в одной строке», карточка на каждую ноду, «Аутбаунды по нодам», «Сравнение нод», «Здоровье панелей», GeoCheck в Grafana.

**Проект**
- README в новом оформлении: баннер, пример алерта, схема, справка в сворачиваемых разделах; английская версия `README.en.md`.
- Автоматизация: Dependabot для образов Docker и GitHub Actions, еженедельная проверка новых версий xray-checker (PR, если патчи легли, иначе issue), релизы по тегу с текстом из `CHANGELOG.md`.
